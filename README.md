# FocusList — Task Manager App

Live App: [https://task-manager-app-sigma-orcin.vercel.app/](https://task-manager-app-sigma-orcin.vercel.app/)

## Overview

FocusList is a lightweight task management web application built to help users organize tasks quickly without the complexity of traditional productivity tools. It is designed for fast task entry, clear tracking, and structured daily planning through a simple and responsive interface.

The app focuses on reducing time in productivity workflows by combining task creation, organization, filtering, and performance tracking in one place.

---

## Features

### Task Management

* Add and delete tasks
* Mark tasks as complete or incomplete
* Live counters for total and completed tasks

### Organization System

* Project folder structure
* Tag-based categorization
* Status filters (All, Active, Completed)
* Search functionality for quick task retrieval

### Control Panel

* Sticky quick-add input for fast task creation
* Sorting options (by date and priority)
* Global search bar

### Task Board

* Card-based task layout
* Kanban-style drag-and-drop support
* Checklist-style task breakdown (where applicable)

### Productivity Tracking

* Progress indicators
* Focus timer for task sessions
* Productivity streak tracking

---

## Tech Stack

* HTML5
* CSS3 (Vanilla)

---

## Purpose

FocusList was built to support freelancers and multi-tasking individuals who need a fast, minimal, and structured way to manage their daily and weekly workload without relying on heavy productivity platforms.

---

## How to Use

1. Open the live app
2. Add a task using the input field
3. Organize tasks using tags, folders, or filters
4. Track progress using completion counters
5. Focus using the built-in timer
